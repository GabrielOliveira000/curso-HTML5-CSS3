Principais formatações de texto

Negrito / Destaque

Nesta frase, temos um termo em negrito usando a tag <b> (não semântica).

Nesta frase, temos um termo em destaque usando a tag <strong> (Semântica)

Itálico / Ênfase

Nesta frase, temos um termo em itálico usando a tag <i> (não semântica).

Nesta frase, temos um termo em itálico usando a tag <em> (semântica).

Texto marcado

Nesta frase, temos um termo marcado usando a tag <mark> (semântica).

Texto grande e pequeno

Estamos criando um texto grande usando a tag <big> que já esta obsoleta, e um texto pequeno usando a tag <small> que ainda é valida.

Texto deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não considerado, usando a tag <del> (semântica).

Texto inserido

Podemos marcar um texto como inserido para dar ênfase e indicar que ele foi adicionado depois, usando a tag <ins> (semântica).

Podemos também fazer o sublinhado com a tag <u> (não semântica)

sobrescrito

Para inserir coisas do tipo x20+3, usando a tag <sup>.

Texto subscrito

Para inserir coisas do tipo H2O, usando a tag <sub>.
